# NHL Tracker v1.7.13

## Kalshi Daily Sync duplicate protection
- Fixes existing manually logged Kalshi bets being incorrectly offered as brand-new wagers when syncing today's orders.
- In addition to matching exact Kalshi order IDs, checks previous manually logged Kalshi wagers by the original wager date, exact player thresholds, market, stake, and odds.
- Matches legacy wagers one-to-one, so separate Kalshi purchases with identical player combinations still remain separately importable.
- Rechecks duplicates immediately before Import All to protect against a stale review preview.
- Adds automated regression coverage for five existing wagers, genuinely separate identical orders, and wrong-date/amount/odds cases.
- Keeps all v1.7.12 features, including the Kalshi setup guide, daily/historical sync separation, and tabbed Settings.

## Install
Close NHL Tracker and run the Windows setup executable attached below. Log in with your existing LIVE account. This upgrade does not require historical backfill or deleting any existing wagers.

## Usage
After updating, use **Sync Today's Kalshi Bets** as normal. Previously logged matching wagers should be skipped. Review new candidates before choosing Import All.

The Windows executable is unsigned, so Windows SmartScreen may display an unknown-publisher warning.
