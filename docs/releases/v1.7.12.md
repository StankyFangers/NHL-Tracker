# NHL Tracker v1.7.12

## Kalshi Sync and Settings
- Adds read-only Kalshi API connection and a detailed, step-by-step Windows setup guide.
- Sync Today's Kalshi Bets in Bet Entry imports only orders placed on the current Eastern calendar date.
- Adds separate Historical Backfill under Settings for older wagers, including date-specific NHL game/player matching and safe duplicate detection by Kalshi order IDs.
- Supports Kalshi combo wagers, a dedicated 2P - 1P category and category backfill with review before changes.
- Runs Daily and Historical scans while navigating inside NHL Tracker, with a persistent progress banner, Windows completion notifications and Cancel Sync.
- Restores the grouped Settings navigation, including Kalshi Sync, sportsbook settings, customization and data management.
- Includes diagnostics and Sync Review for wagers that cannot be matched safely.

## Installing
Download **NHL Tracker Setup 1.7.12.exe** below, close the old NHL Tracker app, run the installer, and log in with your existing account. The installer retains application data on upgrade.

## Kalshi connection
Kalshi credentials are optional. Navigate to **Settings → Kalshi Sync → Guide** for complete read-only setup instructions. You can keep using the tracker without linking Kalshi.

## Important
- Existing LIVE account wagers are not replaced by installation.
- Daily Sync is the normal workflow for existing users; Historical Backfill is optional for importing older missing wagers.
- Scans do not place trades. New wagers require an explicit Import All confirmation after review.
- Windows installer distributed via GitHub Actions is not code-signed; Windows SmartScreen may show an unknown publisher warning.
