# NHL Tracker v1.8.0 — Windows Desktop

## What's new
- Bet Slip: individual player-leg OVER/UNDER selections, readable leg editing, configurable default direction and a compact right-aligned unit size / bet date / clear controls.
- Player-prop Under markets: sportsbook-style lowercase `u0.5P` / `u1.5P` labels; Under wagers only show a winning hit after the game is final.
- Multi-game bets: scoreboard team-unit exposure distributes the wager's stake evenly across distinct represented teams without changing the actual parlay stake.
- Bet Tracker: category labels and bet counts stay white; category running P/L includes money currently at risk; positive and negative totals are green and red. Pending, won and lost wager details use yellow, green and red respectively.
- Sportsbook Defaults: consolidated default sportsbook, unit size, player direction, trio-split units and configurable units by wager category.
- Data Management: separate instructions and actions for Backup Account Data, Restore Account Data, Import Bets, Export Bets and Download Template.
- Bet Categories: removed the obsolete 2P - 1P Historical Backfill control without changing existing wager categories or wager history.
- Kalshi: includes shared NHL player-alias improvements from the development branch.

## Installation
Close NHL Tracker, download and run **NHL Tracker Setup 1.8.0.exe**, and sign in to your existing LIVE account. Existing account data should be retained. This is a desktop installer update, not a migration or a request to re-import historical wagers.

## Notes
- Windows may show a SmartScreen warning for an unsigned installer.
- Advanced sportsbook profile/reporting functionality is not part of this release.
- Additional custom Kalshi alias changes that existed only as uncommitted local files are not included in the published build.
