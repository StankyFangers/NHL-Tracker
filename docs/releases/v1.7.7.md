# NHL Tracker v1.7.7

## Fixed
- LIVE accounts with DEV privileges can generate the Daily Combo PDF from Dev Center. The report previously returned silently because it checked the TEST account instead of the active LIVE account.
- Accounts without DEV privileges receive an explicit message if they attempt to invoke the report.

## Included desktop improvements
- Compact Bet Entry matchup bubbles with team abbreviations, logos, and independent pregame lineup confirmation checks.
- Both teams' confidence breakdowns appear immediately when opening Confidence Breakdown & Comparison.
- Persistent bet slip with combo/player additions, adjustable research area, and keyboard wager entry.
- Cloud save recovery and Full Account Backup wager migration support.

## Install
Download the Windows installer below, close NHL Tracker, and run the installer. Existing cloud users can sign back in to their account.

Users migrating local bets for the first time should export BACK UP ALL DATA from their old installation, then sign in and use Settings → LIVE cloud migration → account-scoped import to select their own Full Account Backup JSON. Preview and confirm the migration. RESTORE FULL BACKUP is a separate local restore tool.

After installing, LIVE DEV users should check Dev Center → GENERATE DAILY PDF, choose a save location, and open the saved PDF.
