NHL TRACKER v1.1

Unified LIVE Command Center: Today's Games scoreboard strip, league/game event filtering, integrated bet accordions, Add Bet drawer, and per-event notification volume controls.

NHL TRACKER v1.0

Run in Git Bash:
  npm install
  npm run dev

V1.0 highlights:
- Approved event icon set
- Intermission / period-end events
- Live detection-order feed
- Editable bets
- Kalshi entry: Units + Pays; American odds derived automatically
- Fanatics entry: Units + American Odds
- Sportsbook autocomplete: type and press Tab to accept
- Bet Hit feed uses standard notation: 1u @ American odds
- Windows desktop notifications
- Per-event Feed / Desktop / Sound controls
- Short, distinct built-in event sounds + master volume
- Spoiler Shield overrides feed, desktop notifications, and sounds
